Website-Aware Chatbot using ChatGPT API

This project is a console-based chatbot built using Python that can answer user questions based on the content of a given website.  
The chatbot scrapes website data, processes it, and uses the ChatGPT API to generate context-aware responses.

---
🔍 Project Overview

ChatGPT cannot directly browse websites.  
To solve this, this project:
1. Fetches website content using web scraping
2. Extracts and cleans readable text
3. Passes the website data as context to the ChatGPT API
4. Allows users to interact with the chatbot via the console

---

 🛠 Technologies Used

- Python 3.x
- requests – for fetching website content
- beautifulsoup4 – for HTML parsing and text extraction
- OpenAI ChatGPT API – for natural language processing
